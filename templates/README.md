## How to Use | 사용 방법 | 使用方法

### 1. Copy Template | 템플릿 복사 | テンプレートをコピー

```bash
# Daily reflection
cp templates/en/daily-reflection.md personal-journey/2025/q1/daily-2025-01-15.md

# Weekly summary
cp templates/en/weekly-summary.md personal-journey/2025/q1/week-01.md
```

### 2. Fill in Your Reflections | 반성 작성 | 反省を記入

Open the copied template and fill in each section based on your learning and experiences.

### 3. Save and Commit | 저장 및 커밋 | 保存とコミット

```bash
git add personal-journey/
git commit -m "[Daily] Developer - Today's learning reflection"
git push
```
